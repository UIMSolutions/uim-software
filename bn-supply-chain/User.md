# User Guide

## Functional areas

- Partners: view suppliers and trading partners.
- Orders: inspect purchase orders and line items.
- Shipments: track carriers and shipment states.
- Ship notices: review dispatch acknowledgements.
- Invoices: view invoice status and amounts.
- Alerts: monitor supply-chain exceptions.

## API overview

- GET /api/v1/partners
- GET /api/v1/orders
- GET /api/v1/shipments
- GET /api/v1/ship-notices
- GET /api/v1/invoices
- GET /api/v1/alerts
