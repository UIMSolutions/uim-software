# NAFv4 Notes

This module follows a layered structure aligned with NAFv4 terminology:

- Domain: business entities and repository contracts for supply-chain collaboration.
- Application: use-case service for the supply-chain network domain.
- Infrastructure: persistence adapters and configuration.
- Presentation: REST controllers and the web client.

The implementation can be extended with additional objects such as forecast, ASN, quality notifications, and collaboration workflows.
