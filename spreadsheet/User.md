# User Guide

## Features

- Create a workbook with title, description, owner, and metadata tags.
- View the workbook list and open individual sheets.
- Query workbook metrics such as row and column counts.
- Use the web client at the root URL to interact with the service.

## API overview

- GET /api/v1/spreadsheets
- GET /api/v1/spreadsheets/:id
- POST /api/v1/spreadsheets
- PUT /api/v1/spreadsheets/:id
- DELETE /api/v1/spreadsheets/:id
- GET /api/v1/spreadsheets/:id/metrics
